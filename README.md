# Сервис управления посылками (ParcelStore)

## БД на основе SQLite

## Основные функции:
- **Регистрация новой посылки** - добавление записи в систему
- **Просмотр информации о посылке** - получение данных по ID
- **Список посылок клиента** - все отправления конкретного пользователя
- **Обновление статуса** - изменение состояния посылки
- **Изменение адреса** - только для статуса "registered"
- **Удаление посылки** - только для статуса "registered"
